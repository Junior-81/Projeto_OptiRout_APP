# OptiRout Android

Base inicial da migracao do projeto para Android nativo com Kotlin e Jetpack Compose.

Escopo desta pasta:
- app Android como principal ponto de interacao
- consumo da API FastAPI existente no backend
- interface voltada para mapa, selecao de modal e comparacao de rotas

Observacoes:
- o backend Python atual permanece como motor de calculo
- esta base foi criada para separar a camada mobile da camada de algoritmo
- a primeira iteracao foca em estrutura, tema visual e tela inicial
